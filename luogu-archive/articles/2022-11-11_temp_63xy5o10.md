# 反复听

## 题目描述

最近，txw同学在学一种很新的东西——IO，但是碍于QI限制，他听不懂sh教练讲课，于是txw同学想到了一个办法——反复听。txw同学有一台机读复REID。他可以在sh教练上课的时候选取一段话语进行录音，比如：txw同学觉得环循算法很难，于是他录了个音，准备回家反复听。可是录到一半，txw发现他的机读复REID弹出了一个窗口“MLE”，哦原来是内存不足啊！这次事故使txw同学的录音全部丢失！于是txw同学找到了你，现在他要在两节课中选择一些知识点进行录音，他升级了他的机读复REID，可以查看在无限个平行宇宙中，每个机读复REID的内存，但是副作用是每一节课只能录音一次。现在txw同学选取了无限个平行宇宙，使得sh老师讲的课程完全一致，并且每个平行宇宙的REID内存容量不同。如果有种录音方案，使得可以刚好用完其内存，那么我们称之为一个录音方案。现在，txw同学想知道每个平行宇宙中的机读复REID，可以有几个录音方案。

## 输入格式

$num_{i}$ 表示第 $i$ 堂课中有几条知识点可以录音， $Mi_{k}$ 表示第 $i$ 堂课中第 $k$ 条知识点的内存占用 ( $i \epsilon[1,2] , k \epsilon[1,num_{i}]$ )。

第一行 两个正整数 $num_{1}$ 、$num_{2}$ 。

第二行 $num_{1}$ 个正整数，第 $k$ 个正整数示 $M1_{k}$ 。

第三行 $num_{2}$ 个正整数，第 $k$ 个正整数示 $M2_{k}$ 。

## 输出格式

第 $i$ 个平行宇宙的录音方案数用 $ans_{i}$ 表示

每个 $ans_{i}$ 的异或

## 输入输出样例

### 输入 #1
```
1 1
2
3
```
### 输出 #1
```
1
```

## 说明/提示

### 【数据范围】

$m \leq 1000$

$\sum_{i=1}^{2}\sum_{k=1}^{m} Mi_{k} \leq 1000$
