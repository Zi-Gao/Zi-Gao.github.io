> 主题示例文章 · 阅读的节奏，藏在字里行间。

我们经常用「顺畅」来形容阅读体验，却很少注意到，顺畅是由许多细小的排版选择共同创造的。

## 让每一行适度停留

一行太长，读完后很难找到下一行的开头；一行太短，眼睛又会频繁换行。可以从适中的正文宽度开始，再结合字号与屏幕尺寸调整。

这个主题让长文保持较窄的阅读区域，同时给目录留出独立空间。在手机上，目录会收起，文字获得完整的可用宽度。

## 行距与段距

行距让同一个段落里的文字保持联系，段距则提醒读者一个想法告一段落。两者不应该完全相同。

```css
.prose {
  line-height: 1.95;
}

.prose p {
  margin-block: 1.4em;
}
```

## 尊重内容自己的层次

短句可以轻快，长段落需要喘息。列表适合并列的信息，引用适合一个值得停顿的声音。

> 排版最好的状态，是你看见了文字，却没有一直注意到排版。

最后，打开手机再读一遍。如果你愿意读下去，通常说明已经走在正确的方向上。
