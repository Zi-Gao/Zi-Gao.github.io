- 而这时 imc 他说想了个 A 的假做法，汗流浃背了。而我开了个 D 并且成功把 D 鉴定为不可做题，摆烂。

- 大佬 imc 大概一个小时的时候想到 B 的正解。然后发现需要高精度四则。再次汗流浃背。我让他写个 cpp 验证代码，然后来改高精度或者py之类的。

- 开始和 fft 大佬肉看看 J 题的规律，首先算搞了个做法，发现居然可以通过整整一个数！然后看出来了 J 题第一行的规律，开始看第二行的规律，先粘了个模数还原分数的板子，结果看到一半 fft 说要不看前缀和和下一项规律，我去！真的有规律，然后对着类似 1/2,3/5,2/3...的系数看了好久，不会。。。

- imc大佬两小时左右终于速战速决把 B 的 cpp 样板代码写出来了，太牛波了，写这么快。然后我去改了个 py。zi_gao 和 fft 这时正在把 J 题的数据打表出来找规律。

- 让 imc 过来看 J 的规律。imc大佬：那这个分子分母的差不是 12 的循环吗？fft（大惊）（尖叫）：拉马努金！！！ 由于我已经写了 J 的第一行计算公式，所以我来写 J。过了 20 分钟他们就切掉了 J。

- 此时 imc 大佬改 py 一直没该对，会 TLE，特判了个 k=2 过了一会 python 爆高精了（re）。中途又尝试改个 cpp 的高精 fft，tmd没一个带fft或者压位的模板，全都不能用。蚌埠住了，又去搞 py，请教了隔壁大佬 hyj，说是 python 数字转字符串有长度限制，需要用一个 `sys.set_int_max_str_digits(0)` 来去掉限制，然后就过了！！

- 此时我们一共切了 4 道。然后晚饭时听说 G 可以直接爆搜，各位大佬一直 fAKe 说不会爆搜？？？让我写好吧，吃完饭就回去写 G 了

- 很快写了个没剪枝的爆搜，发现过不了，又写了两个剪枝过不了！写了一个剪枝然后翻转了一下序列，还是过不了。突然发现直接爆搜会偏向往一个序列里面放数，很不平衡，可能比较慢，然后平衡了一下，奇偶性判断一下优先搜哪边就过了。

- 可以开香槟了（然而并不行，只做了 5 道）。

- 然后发现 H 是同余最短路，让我现学同余最短路，imc 和 fft 开始写游记摆烂了。

- 然而同余最短路假了摆烂！5 题遗憾离场。

- 去问了隔壁对 szz 为啥样例是这样的，**告诉我读错题了！**瞬间小脑萎缩的感觉，把之前爆搜改了改打个表过了。

- imc 看了看 J 不会就去开 F，发现是个简单题开始写。

- 在中途 fft 一直再调 E 题，为啥做这么久呢？**因为他读错题了 2 次**，当然没关系够了就行。我去开了 I 题，想了几个策略，hack 了自己几次，最后那个策略感觉 hack 不掉但是就是不过，不知到啥问题，然后这个题就不了了之了。

- 最后 20min imc的 F 题 TLE on 11 了，三个人一起帮他卡常，到最后我感觉这个 set 可能是瓶颈，按照套路这种 set 可能可以用可删堆优化，全局查看了一下这个 set 的调用还 tmd 真的只需要最小元素。现在只有 10min 了，汗流浃背中，急急忙忙开始改可删堆，然后发现我的板子在洛谷上，但是洛谷登录不了，于是去 imc 的机子上登录洛谷，很快改完了啊，提交！下面是最汗流浃背的一集，三个人盯着屏幕看着看着一个一个点过，到第 11 个点时感觉都要窒息了，读秒 1 2 3 4 5 过了！！！！！然后就是第 12 个点，13，14，15，16。。一直数到了30多40个点，屏幕上挂起一抹绿色 Accept！！！！

虽然只做了 5 题，无缘决赛，想起来还是非常可惜，都错题一直都是最大的问题，一上来直接心态搞炸，稍微少一点失误说不定还可以过更多题，但是让我很开心的是我们都没有因为队友的失误而责怪某一方，团结合作永远是最重要的！
